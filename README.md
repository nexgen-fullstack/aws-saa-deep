# AWS SAA-C03 з нуля — глибоке навчання, уроки, шпаргалка

Курс українською до іспиту AWS Certified Solutions Architect – Associate (SAA-C03) для людей,
які **ніколи не мали справи ні з комп'ютерами, ні з хмарою**.

Маршрут: 🧠 глибоке навчання → 🎓 24 короткі уроки → 📘 шпаргалка (29 розділів) → 🎲 квіз по тригерах →
📝 практичний тест (65 питань) → 🏆 іспит. Є схеми, довідник сервісів із підказками, PDF-версії.
Працює як застосунок на телефоні й офлайн.

**Глибоке навчання** — книжка з 47 розділів (11 частин): від того, що всередині комп'ютера, до архітектури
у двох регіонах і розборів питань іспиту. Наскрізна історія — пекарня «Хмаринка» у Львові (Оля і Тарас).
152 ілюстрації, 316 питань у міні-тестах, словнички, «Головне», вправи в справжньому AWS.

## Структура

- `docs/` — готовий сайт: `index.html`, офлайн-режим (`sw.js`, `manifest.webmanifest`), іконки, PDF.
- `_source/deep/` — розділи глибокого навчання (`NN_*.md`), ілюстрації `fig/*.svg`, правила письма `PLAN.md`.
- `_source/lessons/` — уроки курсу: блоки `===` метадані `===` текст.
- `_source/sheet/` — розділи шпаргалки (Markdown).
- `_source/services.md` — довідник сервісів для підказок.
- `_source/questions.md` — питання практичного тесту.
- `_source/build.py` — збирає сайт і PDF; `_source/figcheck.py` — контактні аркуші ілюстрацій для перевірки очима.

## Збірка

```bash
python _source/build.py
```

`--no-pdf` — лише HTML, без іконок і PDF (потрібен Chrome або Edge для PDF).

Перевірити ілюстрації: `python _source/figcheck.py назва1 назва2` (або `--all`, `--dark`) — PNG у `_source/_figcheck/`.

Незалежний навчальний матеріал, не пов'язаний з Amazon Web Services і не схвалений AWS.
Практичні питання — оригінальні, це не реальні питання іспиту.
